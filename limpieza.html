    Chuleta de comandos y limpieza

    Todo lo esencial del laboratorio en una página. Añade sudo ip netns exec NOMBRE delante para ejecutar cualquier comando dentro de un namespace.

    AcciónComando

    Listarip netns list

    Solución de problemas

    SíntomaCausa probableComprobar
    Network is unreachableNo hay ruta (falta default o IP)ip route, ip route get IP
    Destination Host UnreachableNadie responde al ARP: equipo apagado, IP mal, interfaz downip neigh (FAILED), ip link
    Ping sin respuesta ni errorFalta ruta de vuelta, ip_forward=0, cortafuegos DROPtcpdump en cada salto: ¿dónde desaparece?
    NO-CARRIER / LOWERLAYERDOWNEl otro extremo del veth está apagadoip link en el otro namespace
    RTNETLINK answers: File existsLa IP, ruta o interfaz ya existíaUsa replace o borra antes
    Cannot open network namespaceEl namespace no existe o lo borrasteip netns list
    Connection refusedNadie escucha en ese puerto (RST) o REJECTss -tlpn en el servidor
    Conexión se queda colgadaDROP en un cortafuegos o paquete perdidoiptables -L -v (contadores)
    Paquetes grandes fallan, pequeños noMTU distinta en algún enlaceping -M do -s 1472, tracepath
    El servidor responde a sí mismo pero no fueraEscucha en 127.0.0.1ss -tlpn (columna Local Address)
    Address already in useOtro proceso (quizá de otra práctica) usa el puertoss -tlpn, ip netns pids NOMBRE

    Limpieza total

    Para cada namespace que quede, primero mira si tiene procesos vivos (servidores, dnsmasq, sshd…):

    host
    $ ip netns list
$ sudo ip netns pids pc1
# Si sale algún PID, termínalo
$ sudo kill PID
# Borrar un namespace
$ sudo ip netns del pc1

    Atajo para borrar todos los namespaces con nombre de una vez (si usas otras herramientas que creen namespaces en /run/netns, también los borrará):

    host
    $ sudo ip -all netns delete
$ ip netns list

    Ficheros que el laboratorio puede haber dejado:

    host
    $ ls -d /etc/netns/* /tmp/lab-* ~/lab-tcpdump
# Borra solo las carpetas del laboratorio que aparezcan arriba
$ sudo rm -r /etc/netns/cli1 /etc/netns/cli2 /etc/netns/pc1
$ sudo rm -rf /tmp/lab-*

    Y los cambios del apartado de permisos (si lo hiciste):

    host
    $ sudo rm /etc/sudoers.d/lab-redes
$ sudo userdel -r alumno
$ sudo groupdel redes
$ rm ~/lab-tcpdump

    Tu red real nunca se ha tocado salvo en el extra opcional "dar Internet real a un namespace" de la capa 3, que tiene sus propios pasos para deshacerlo.
